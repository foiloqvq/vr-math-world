## 判据（每张图自问）

1. 透视对吗？（平行线有没有都收向消失点）
2. 能只看剪影就认出是什么吗？
3. 明暗能立起来吗？（挡住颜色只看黑白灰）
4. **这张是给谁看的？**（玩家 / 建模 / 练手）—— 答不出来就该扔
