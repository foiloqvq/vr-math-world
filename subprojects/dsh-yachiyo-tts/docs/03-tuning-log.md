# 调参日志（每条都带实测数字）

> 结论先行：**处理层能改"响度、亮度、速度"，改不了"说话起伏"；音色/语气的根在模型与参考音频。**

## 1. 响度（模型输出偏小）

`ffmpeg -af volumedetect` 实测：

| 版本 | 平均 | 峰值 | 6kHz 以上 |
| --- | --- | --- | --- |
| 模型原始输出 | -22.5 dB | -4.5 dB | -44.5 dB |
| 方案 A：只加固定增益 | -17.1 | 0.0（顶到满刻度，有削波风险） | -39.0 |
| 方案 C：压缩+三段 EQ+限幅 | -17.0 | -1.6 | -32.9 |
| **最终采用：只提响度不染色** | **-17.9** | **-1.4** | **-39.6（≈原始+增益）** |

教训：**"更清脆"和"更 AI"是同一个动作的两面**——把 6 kHz 以上抬 12.5 dB，抬起来的不只是齿音，
还有声码器伪影，听感反而更假。最终版**只提响度、不做音色染色**。

坑：`alimiter` 默认 `level=1` 会把输出**自动归一化回 0 dB**，`limit` 设 0.85 也没用；
必须写 `alimiter=limit=0.85:level=disabled` 才真正留出余量。

## 2. 分段策略（"断断续续的合成音"）

上游默认 `text_split_method=cut5`（按标点切）+ `fragment_interval=0.3`（片段间硬插 0.3 秒静音）。
同一句话实测：

| 设置 | 时长 |
| --- | --- |
| cut5 + 0.3s | **7.86s** |
| **cut0（不切分）+ 0.05s** | **6.93s** |
| cut0 + 0.05s + 语速 1.08 | **6.21s** |

少掉的近 1 秒**全是句中被塞进去的静音**。这就是"一段段拼起来"的来源。

## 3. 采样温度（以为能稳音高，其实不能）

同样 5 段文本分别合成，测每段中位基频的波动：

| 温度 | 各段中位 f0 | 整段跨度 | 最大边界台阶 |
| --- | --- | --- | --- |
| 1.00 | 308 344 327 332 299 | 2.43 半音 | +1.97 |
| 0.85 | 308 333 330 333 312 | 1.94 | +1.68 |
| 0.70 | 308 340 325 344 323 | 1.94 | +1.75 |
| 0.55 | 315 348 337 314 330 | 1.79 | +1.70 |

降温度只把跨度从 2.43 压到 1.79，**台阶始终 ~1.7 半音**。说明根因不是"采样太自由"，而是**块太多**。

**真正的解法是减少块数**（宿主分块 6s → 16s）：

| 指标 | 块 6 秒 | 块 16 秒 |
| --- | --- | --- |
| 分块数 | 6~7 | **2** |
| 接缝 | 6 个（5 个明显） | **1 个** |
| 最大边界台阶 | 1.13 半音 | **0.35 半音** |
| 整段音高跨度 | 1.77 半音 | **0.35 半音** |
| 首段可用 | 2.0s | 3.2s（代价很小） |

## 4. 超采样（减少毛刺）

`super_sampling=True`，同一段文本对比（突变点 = 采样点突变计数，毛刺代理指标）：

| 选项 | 突变点 |
| --- | --- |
| 现状 | 19 |
| **超采样** | **9** |
| 采样步数 48 | 27（更差，不用） |
| 超采样+步数 48 | 21 |

## 5. 参考音频（最大的杠杆，但受素材质量限制）

| 参考来源 | 合成后突变点 | 结论 |
| --- | --- | --- |
| 一键包内置 `cankao.wav` | 16~29 | **最干净**（停顿底噪 -98.6 dB = 数字静音） |
| 官方 PV 视频（66→146 kbps） | 91 | 降级：语音是"短句+停顿"，且有压缩痕迹 |
| 语音全集某段（7.7s） | 4 | 突变点低，**但停顿底噪只有 -39 dB**（底下压着 BGM/房间音）→ 听感有"杂音" |

**关键教训**：一个"低突变点"不等于"干净"。突变点会受**亮度**影响，测不出**噪声**。
选参考音频必须同时看：停顿底噪（越低越好）+ 是否有连续长句 + 素材码率。
本次最终**保留内置参考**。
