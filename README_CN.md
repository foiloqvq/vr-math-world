## 项目概述
VR Math World 是面向PC与VR双端开发的开放世界沉浸式虚拟环境，整合数学可视化、交互式阅读空间、基于大模型的AI陪玩智能体、用户生成内容(UGC)系统以及游戏内代币经济体系。

本项目旨在构建一个可供用户精神休憩的虚拟栖息地，融合休闲玩法与轻量化学术探索，打通娱乐体验与数学学习之间的壁垒。用户可在持久化虚拟世界中自由漫游、与AI智能体对话交互、探索可视化数学结构、上传自定义角色模型，并参与虚拟社交活动。

## 核心设计目标
1. **双平台支持**：PC桌面端与VR头显原生运行，共享统一世界场景。
2. **数学可视化模块**：专门用于数学符号展示、形式化推演与交互式几何探索的阅读空间。
3. **AI社交子系统**：由大语言模型驱动的非玩家智能体，作为世界内陪伴、对话与交互实体。
4. **UGC内容管线**：去中心化用户资源上传、模型预览、自定义角色与场景道具权限管理。
5. **闭环世界内代币经济**：非加密货币的游戏内代币体系，采用“可肝、付费仅加速”的资源获取模式。

## 开发路线
- **阶段1 — 文档与知识库（当前阶段）**
项目规范、需求分析、数学术语语料库、系统架构设计、风险评估。
- **阶段2 — 原型实现**
基础场景框架、玩家移动、数学可视化沙盒、AI智能体原型。
- **阶段3 — 功能迭代**
UGC资源上传系统、代币经济、多人社交模块、跨平台兼容性优化。
- **阶段4 — 硬件与生态探索**
自研VR硬件研究、社区生态拓展、内容审核与年龄分级体系。

## 架构特点
项目采用模块化架构，将渲染引擎、世界逻辑、AI服务、资源管理、经济子系统解耦，便于各模块独立迭代。内容审核与年龄访问控制作为底层横切模块内置在系统中。

## 代码结构

| 目录 | 内容 |
| --- | --- |
| `prototype/` | **网页原型**（Three.js）：星空场景 + 第一人称走动 + 三件数学展品 —— 改数学内容最快的试验田 |
| `unity/` | **Unity 侧**（正式引擎）：网格数学、展品组件、场景搭建脚本、Editor 搭建清单 |
| `tools/meshmath-test/` | **引擎外**验证网格数学的测试（`dotnet run`）：顶点/索引/包围盒/单面性不变量 |

网格数学刻意做成不依赖 UnityEngine 的纯 C#，因此**装引擎之前就能编译并测试**。
