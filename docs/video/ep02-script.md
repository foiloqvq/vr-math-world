## 三、配音稿（7 句，TTS 用）

```
公元前五百年，有人因为一个数字被扔进了海里。
那个数字，是根号二。
他叫希帕索斯。他证明了：正方形的对角线，写不成两个整数之比。
而当时的学派说，万物皆分数，这是他们的教义。
一点四一四二一三五六，永远不循环，永远不重复。
所以它不叫没道理，叫无理。它只是没法用分数表达。
我是大肥鱼，下期我们走进黎曼面。
```
