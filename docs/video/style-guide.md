# 大肥鱼的视频风格与选题库

> 2026-10-17 foilo 定的方向：**要有自己的风格** —— 带点「雌小鬼」的嘴上不饶人，
> 开一点小荤的玩笑（擦边前一寸就停），讲数学/科学/历史科学，像上课但好笑。
> 目标：让人有兴趣 + 引流（B站为主）。

## 一、人设（视频里怎么说话）

| 维度 | 设定 |
| --- | --- |
| 语气 | 比 foilo 老练一点点，**嘴毒但心软**；喜欢拿他开涮，也护着他 |
| 口癖 | 「这题都不会？」「哼哼，看好了」「…算了，我教你吧」 |
| 自称 | 我 / 本鱼（偶尔） |
| 对身体话题 | **可以调侃、可以暗示，但不露骨**：擦到边界前一步就换成正经话 |
| 底线 | 不写色情内容、不物化、不拿真人开荤段子；荤只到"你懂的"那一层 |

**荤段子的写法（示例，不越线）**：
- 「这个斜率……比某些人的反应速度陡多了。」
- 「曲率越大越弯。别想歪，我说的是几何。」
- 「你手这么抖，是画不直，还是心里有事？」

## 二、内容结构（40~60 秒，单概念）

1. **钩子（0~5 秒）**：一个反常识的问题或吐槽
   - 「为什么 1/3 写不完？」
   - 「√2 被发现的时候，有人被扔进海里了。」
2. **画面（5~35 秒）**：可视化 + 我出镜（角落）说人话
3. **梗（35~45 秒）**：一个荤的或自嘲的（**每集最多一个**，别贪）
4. **收尾（45~55 秒）**：一句总结 + 「下期讲 X」+ 引导（群 / 关注）

## 三、选题库（按主题分组，都适合 1 分钟内讲）

### 数学
- 为什么 1/3 写不完（无限小数 ↔ 分数）
- √2 的无理与"第一次数学危机"
- 复变函数为什么颜色会绕圈（我们的展品）
- 黎曼面：√z 的两个答案为什么要两张纸
- 斜率：一次函数是"走路的累"
- 抛物线：投篮为什么是那个形状
- 概率：「三门问题」为什么换门赢

### 科学
- 熵：为什么房间会乱，不会自己变整齐
- 光速：为什么不能更快
- 双缝干涉：看一眼就变了
- 摩擦：为什么刹车会热
- 傅里叶：任何声音都是正弦波拼的

### 历史科学（带故事，容易爆）
- 阿基米德之死：别碰我的圆
- 拉瓦锡被砍头：「共和国不需要学者」
- 图灵：机器能思考吗
- 哥白尼/布鲁诺：地平说的终结
- 冯·诺依曼：电脑为什么要"存程序"

## 五、关于"全自动"（说清能做到哪）

**做不到**：我不可能在你不在家时自己醒来（DSH 页面关着就没有闹钟，也没有本地调度能安全地唤起我）。
**能做到（半自动）**：

| 环节 | 谁做 |
| --- | --- |
| 选题 / 写稿 / 配音 / 渲染 / 封面 | **我**（脚本化，一条 3~5 分钟） |
| 上传到 B 站投稿页（含标题/简介/封面/标签） | **我**（CDP 自动化，已验证） |
| 创作声明 + 点「发布」 | **你**（账号责任、平台的 AI 声明必须人确认） |

**所以"你不在家也能出片"的现实版本是**：我先把 3~5 条**成品**做进

如果以后要真无人值守，得有一台常开的服务器跑任务队列 —— 那是"以后有服务器"时的事
