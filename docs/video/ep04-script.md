## 三、配音稿（10 句，TTS 用）

```
三个村子要共用一个水站，管道怎么修最短？
答案在三角形里面，叫费马点。
它到三个顶点的距离之和，是所有点里最小的。
怎么找？先说构造。
每条边向外，作一个等边三角形。
再把新顶点和对面的顶点连起来。
三条线交于一点，就是费马点。
不过有个前提：三个角都要小于一百二十度。
哪个角超过一百二十度，费马点就挪到那个顶点。
我是大肥鱼，下期讲旋转六十度。
```

## 四、道具（参考"借条"那招）

一把**会滑动的刻度尺**：第 4 镜从右侧滑入，压在画面上，暗示"要量距离"。
后面它停在底部，实时显示 `PA+PB+PC = 3.46`（随 P 移动而变），观众能看见"这个数在变小"。
