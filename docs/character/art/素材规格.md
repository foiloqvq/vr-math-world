# 立绘/素材规格（foilo 画，我自动处理）

> 目的：板子到了以后，你不管画成什么样，我都能一键转成视频能用的素材。
> 原则：**你只管画得开心，规格我来兜**。

## 一、画布与导出

| 项 | 要求 | 为什么 |
| --- | --- | --- |
| 画布 | 2000×2000 或 1400×1400 | 够大，缩到 1080p 不糊 |
| 格式 | **PNG** | 要透明 |
| 背景 | **透明**（Krita/PS 里删掉背景层） | 我要贴到视频上 |
| 线宽 | 别太细（≥3px @1400） | 缩小后细线会消失 |
| 留白 | 四周留 60px | 我裁切时不会切到头发 |

## 二、命名（重要，只影响我找得到）

```
大肥鱼-<类型>-<内容>.png
```

- 类型：`立绘`（全身） / `半身` / `表情` / `动作` / `道具`
- 内容：自由写

例子：
- `大肥鱼-立绘-水手服.png`
- `大肥鱼-表情-生气.png`
- `大肥鱼-动作-指屏幕.png`
- `大肥鱼-道具-粉笔.png`（如果要给我一个工具）

## 三、我需要的"最小素材包"（第一批就够）

| 素材 | 数量 | 用在哪 |
| --- | --- | --- |
| 立绘（全身，站姿） | 1 | 视频角落常驻 / 结尾 |
| 半身（说话姿态） | 1 | 讲课段落 |
| 表情差分（喜/怒/惑/羞/疲） | 5 | 切换情绪 |
| 动作：指屏幕 | 1 | 讲到重点时 |

## 四、我这边怎么处理（你不用管）

1. `tools/prep-art.py` 批量：去背景 → 裁到内容边界 → 统一高度 → 输出到 `docs/character/art/ready/`
2. 渲染器直接读 `ready/` 里的图
3. 视频里默认放在右下角，高 170px、浮动 5px

## 五、如果你画的是"一整张表情总览"（九宫格那种）

也行 —— 告诉我格子数，我用 `prep-art.py --grid 3x3` 自动切。

## 六、画的顺序建议（省力）

1. 先画**一个站姿全身**（这个最重要，能顶所有镜头）
2. 再画**五个表情头像**（能拼到全身头上）
3. 最后画动作（指屏幕、拿粉笔）—— 有就更好，没有也能发
