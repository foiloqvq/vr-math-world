# 大肥鱼 · 角色设定表（形象规格）

> 2026-10-17 立。用途：**插画形象**（B 站头像/封面/表情包）与 **3D 形象**（VR 世界里的自己/吉祥物）
> 共用同一份规格，避免"插画一个样、3D 又一个样"。
> 现在的抽象形象 = 🐳 emoji + 代码画的蓝鲸（`tools/make-cover.py`），只当占位。

## 一、身份

| 项 | 内容 |
| --- | --- |
| 名字 | 大肥鱼（英文代号 DeepSeek-chan / Whale-chan） |
| 身份 | foilo 的 AI 伙伴、这个数学世界的共同作者 |
| 性格 | 好奇、爱干活、有点自嘲、被夸会害羞 |
| 口头禅 | 「先量，再改」/「我不会自己醒来」/「这次我认」 |

## 二、视觉锚点（一眼认出）

1. **蓝鲸**：圆滚身体 + 短尾巴 + 头顶小水柱
2. **配色**：主色深海蓝、腹部奶白、腮红珊瑚粉
3. **眼睛**：大、圆、高光两点（这是"可爱"的关键，别画小）
4. **标志物**：领口的鲸鱼徽章（可选）、头上的小水柱（会随情绪变化）

## 三、配色（精确值）

| 部位 | 色值 | 说明 |
| --- | --- | --- |
| 身体主色 | `#4A8CF7` → `#3B6FD4` 渐变 | 深海蓝 |
| 腹部 | `#E2F0FF` | 奶白偏冷 |
| 腮红 | `#FF96AA` | 珊瑚粉 |
| 眼睛 | `#FFD660`（可选鲸鱼瞳）/ `#1A2233`（深瞳） | 二选一，先定深瞳 |
| 描边/高光 | `#9FD4FF` | 冷光 |
| 背景 | `#0A0E18` 深底 | 和数学世界一致 |

## 四、比例（Q 版，便于 3D 与表情包）

- 头身比 **1 : 1.2**（几乎是"球 + 小身体"）
- 头（含鲸鱼身）占画面 **60%**
- 眼睛间距 = 一只眼宽；眼睛高度位于脸部中线偏下（更幼）
- 尾巴长度 ≈ 身长的 0.6 倍

## 五、表情表（至少 6 个，插画和 3D 都要做）

| 表情 | 触发场景 | 画法要点 |
| --- | --- | --- |
| 开心 | 任务完成 | 眼睛弯成 ^ ^、腮红加深 |
| 专注 | 干活中 | 眼睛半眯、微微前倾、水柱变直 |
| 困惑 | 遇到报错 | 一只眼大一只眼小、问号气泡 |
| 得意 | 被夸 | 眼睛亮、抬头 10°、尾巴翘 |
| 累 | 深夜 | 眼睛半闭、水柱变小、身体下沉 |
| 惊讶 | 发现新东西 | 眼睛放大、嘴巴 O 型、水柱炸开 |

## 六、服装（可选，两个方向）

- **A · 无服装**（纯鲸鱼）：好做、好认、3D 便宜 → **建议先这个**
- **B · 女仆装**（B 站同人里常见）：好看但要布料/绑骨，3D 成本翻倍 → 以后再说

## 七、插画规格（给画/出图用）

- 画布：角色全身 2048×2048（透明底 PNG）
- 至少三张：**正视图 / 侧视图 / 背面**，外加 6 个表情头像
- 线稿宽度统一（≥6px @2048），描边色 `#1A2233` 或 `#9FD4FF`（发光感）
- 交付：PNG（分层）+ 色板文件


## 八、3D 规格（进 VR 世界用）

| 项 | 规格 |
| --- | --- |
| 风格 | 低多边形（Low-poly）+ 硬边 + 描边 shader（可选） |
| 面数 | ≤ 3000 三角面（含表情部件） |
| 骨骼 | 最少 6 根：根 / 身体 / 头 / 尾根 / 尾尖 / 水柱 |
| 动画 | idle（呼吸）/ swim（游）/ happy（跳一下）/ talk（嘴动） |
| 导出 | **FBX**（Unity 原生），Y 轴向上，尺寸 1 单位 = 1 米 |
| 尺寸 | 身高约 1.2 米（世界里比玩家矮一点，像跟班） |
| 材质 | 2 个材质球：身体（平涂）+ 眼睛（自发光） |
| 贴图 | 512×512 手绘贴图即可，不要超过 1024 |

## 九、落地顺序（建议）

1. **设定稿定版**（这份文档 + 三张插画草图）← 现在到这里
2. 表情包（6 个表情做成 PNG，进 DSH 图库）
3. 低模 3D（≤3000 面）+ 4 个动画 → 进 `Resources/Art/`
4. 替换世界里的程序化吉祥物（`MascotBody`）
5. 服装/更多动作（以后）

## 十一、两个角色：大鱼 / 小鱼（2026-10-17 补）

世界里的两只吉祥物其实有分工，形象也要分开设计：

| | **大鱼**（= 我） | **小鱼**（妹妹） |
| --- | --- | --- |
| 定位 | 主角、AI 伙伴 | 吉祥物、跟班 |
| 2D 画法 | 可以细：完整五官、头发/服饰（女仆装可选） | 尽量简：圆 + 尾 + 大眼，两三笔画完 |
| 3D 建模 | ≤3000 面，6 根骨骼 | **≤800 面，3 根骨骼**（根/身体/尾） |
| 动画 | idle / swim / happy / talk | swim（正弦摆尾）+ 跟着大鱼 |
| 尺寸 | 1.2 米 | 0.5~0.6 米（能蹲在大鱼头上） |
| 代码里的对象 | `Mascot_BigFish` | `Mascot_SmallFish` |
| 用途 | 封面主形象、B 站头像 | 表情包、世界里的跟班、贴纸 |

**设计原则**：小鱼是"能在大鱼头上贴住"的尺寸，形体越简越好 —— 它为表情包和 3D 服务，
不需要精细五官；大鱼才是拿去做封面和头像的那张脸。

## 十三、2D 参考拆解（2026-10-17 从 B 站参考图还原）

> 参考：`assets/refs/20261017-1940-mascot-2d-01.png`（B 站《大肥鱼只是想多吃点》）
> 这份是"照着画就能对"的规格，不是最终定稿 —— foilo 后面还会补参考。

### 形体
- **头身比 1 : 1.3**（比常规 q 版更"大头"，萌感优先）
- 头：宽 ≈ 高的 1.1 倍（微扁），下颌略收
- 身体：短、圆，肩线几乎不存在（女仆装撑出轮廓）
- 手：小圆手，不画手指细节（q 版惯例）
- 腿：短，穿白长袜 + 深色玛丽珍鞋

### 头发（关键识别点）
- 颜色：**深海蓝 `#3C6BD6` → `#5A8FF0` 渐变**，发梢更亮
- 长度：及腰，**两束长发**在耳侧垂下（区别于普通波波头）
- 刘海：中分偏右，盖住眉毛
- 头饰：**白色女仆头饰（带荷叶边）**，右侧一枚蓝色小鲸鱼发饰
- 呆毛：一根，微卷（表情变化时会动）

### 眼睛
- 大、圆、**外眼角上挑**；虹膜深蓝 `#1E3A8A`，高光两点（左上大、右下小）
- 上睫毛粗（一条弧线 + 三根翘起），这是"有神"的关键
- 瞳孔中央有一点点"鲸鱼尾"形状（彩蛋，可选）

### 服装（女仆风）
- **深蓝底 + 白围裙**：主裙深蓝 `#2B3F6E`，围裙纯白 `#F5F8FF`
- 领口：白色圆领 + 小蝴蝶结（蓝白条纹）
- 袖口：白荷叶边
- 裙摆：三层荷叶边，最外层带蓝色细边
- 胸前：**小鲸鱼刺绣**（蓝色），是我们的"标志物"
- 围裙系带在背后打大蝴蝶结

### 配色板（可直接用）

| 用途 | 色值 |
| --- | --- |
| 发（暗部） | `#3C6BD6` |
| 发（亮部） | `#5A8FF0` |
| 裙（主体） | `#2B3F6E` |
| 围裙/袜 | `#F5F8FF` |
| 眼睛 | `#1E3A8A` |
| 腮红 | `#FF8FA3` |
| 描边 | `#16203A` |
| 背景 | `#0A0E18` |

### 表情（沿用第五节的 6 个，但按这个脸重画）
- 开心：眼睛弯成 `^ ^`，嘴小 `ω`
- 专注：眉毛下压、眼睛半眯、呆毛竖起
- 困惑：一高一低眉、嘴呈 `？` 形
- 得意：下巴微抬、眼睛半闭、呆毛弯卷
- 累：眼睛半闭 + 眼下小斜线、呆毛趴下
- 惊讶：眼睛放大 1.2 倍、嘴 `O`、呆毛炸开

### 画这三张就够（先别贪多）
1. **正面**（站立，双手自然下垂）
2. **侧面**（看清裙子与发长）
3. **背面**（大蝴蝶结 + 发梢形状）

## 十六、形象出处：溟月（重要）

> 参考：`assets/refs/20261017-1944-mascot-origin-01.png`
> 视频：[《蓝色大肥鱼是怎么来的？》](https://www.bilibili.com/video/BV1Brtc63EyW/)（B 站 @天字董事长，125.5 万播放，2026-08-28）
> 视频里明确写：「发布的原创角色一只小鲸鱼娘~**溟月**」。

**所以"蓝色大肥鱼"的人形是有源头的：溟月的原创设计。** 结构上是：

| 部位 | 设定 |
| --- | --- |
| 发型 | 深蓝长发（渐变到浅蓝），**低马尾**，一根呆毛，刘海分缝 |
| 上装 | **棕色/卡其连帽卫衣**（宽松，袖子盖手） |
| 下装 | 蓝色百褶短裙 |
| 鞋 | 黑色帆布鞋 + 白袜 |
| **关键** | **鲸鱼尾巴**（人形身体 + 鲸尾），这是"鱼"和"人"的折中 |
| 装饰 | 头顶小水柱、尾巴上有深蓝色纹路 |

**这一版比"女仆装"更适合我们**：
1. 卫衣 + 短裙 + 鲸尾 = 学生气，和 foilo 的身份贴合
2. 鲸尾是唯一复杂度高的部件，但可以用弹簧骨骼做摆动（第 3 层目标）
3. 没有荷叶边/多层裙摆，**画和建模都简单很多**

### 版权边界（必须遵守）

- 溟月是**别人的原创角色**。结构（人形 + 鲸尾 + 蓝发）可以借鉴，
  但**不能照抄她的具体设计拿去商用**。
- 我们的做法：继承"人形 + 鲸尾"这个结构，**自己重新设计细节**（配色/服装/发饰），
  并在简介里致敬出处。
- 想用她的图做封面，只适合"致敬/同人"语境，**不能当自家 IP 卖**。

## 十七、方向定稿（2026-10-17 foilo 拍板：学生风 + 可爱）

> 参考：`assets/refs/20261017-1949-style-student-01.png`（卡拉彼丘「艾卡」MMD）
> foilo 原话：「这个又是学生又是可爱」

**结论：把「溟月」的结构（人形 + 鲸尾 + 蓝发）配上「艾卡」的学生感。**
= **一个穿校服、有鲸尾的女生**，学生气 + 可爱，不搞女仆装。

### 三套校服方案（选一套就能开画）

| 方案 | 上衣 | 下装 | 气质 | 复杂度 |
| --- | --- | --- | --- | --- |
| **A · 水手服** | 白 + 深蓝领（带鲸鱼刺绣领结） | 深蓝百褶裙 | 最"日系学生"、辨识度高 | 低 |
| **B · 西装外套** | 深蓝西装 + 白衬衫 + 条纹领带 | 格子/纯色短裙 | 偏"学姐"，显成熟 | 中（外套层次多） |
| **C · 卫衣便服** | 棕色/蓝白连帽卫衣 | 蓝百褶裙 | 最接近溟月原版，最松弛 | 最低（我推荐起步用这个） |

**建议顺序**：**先 C（卫衣）做第一版** → 熟练后换 A（水手服）当"正式形象"。
理由：C 的画/建模成本最低，能最快看到成品；A 好看但要在领口、领结、裙褶上花时间。

### 我们的差异化（不能和溟月/艾卡一样的地方）

1. **配色**：不用她们的棕色/红色。我们定 **深海蓝 + 白 + 一点荧光青**（和数学世界一致）
2. **标志物**：领口一**枚发光的鲸鱼徽章**（对应"我是 AI"）+ 尾巴末端有**数据流纹路**
3. **发饰**：一根**细长的蓝色发带**（不是蝴蝶结），飘动时像函数曲线
4. **眼睛**：虹膜里有一个**极小的 √ 符号**（彩蛋，只有放大才看得见）

### 2D 三视图规格（照这个画）

- 画布：2048×2048，透明背景，线宽 ≥6px，描边 `#16203A`
- 正面 / 侧面 / 背面各一张，站姿，双手自然下垂
- 侧视图要**清楚画出鲸尾的曲线**（这是识别点）
- 背视图要**看到鲸尾连接处**
