# 角色与动画方案（卡拉比丘式丝滑移动）

> 2026-10-17 foilo 定方向：**不要米哈游那种站桩**，要「一走路整个人就动起来」的丝滑感；
> 参考卡拉比丘 / VRChat 的全身动作；以后可以上动补；布料/软一点更好看。
> 这份是给"下一件大事"用的方案，不是马上全做。

## 一、现在是什么

| 东西 | 现状 | 问题 |
| --- | --- | --- |
| 玩家身体 | 程序化大肥鱼（`MascotBody`） | 没有腿、没人形骨架，谈不上"走路" |
| 吉祥物 | 同一套程序化鱼 + 尾巴/鳍正弦摆动 | 能动，但只有"游泳感"，没有人形移动 |
| 相机 | 第一/第三人称可切 | 第三人称已经够用 |

**结论**：想要卡拉比丘那种感觉，必须换成**人形模型 + 人形骨架 + 动画片段**。

## 二、四层目标（由易到难，逐层加）

### 第 1 层：能走（1~2 天）

- 模型：CC0 人形（推荐 **Quaternius** 的 CC0 角色，或 **Mixamo** 的免费角色）
- 骨架：Unity **Humanoid** 类型（必须在导入设置里选 Humanoid，不是 Generic）
- 动画：Mixamo 免费片段 **Idle / Walk / Run**（免费商用，需 Adobe 账号）
- 混合：`Animator` + **1D Blend Tree**（参数 `Speed`，0=Idle，0.5=Walk，1=Run）
- 驱动：`SurfaceWalker` 把当前速度写进 `Animator.SetFloat("Speed", speed/walkSpeed)`
- 判据：**按 W 时脚在动，停下时呼吸起伏，速度变化时过渡不抖**

### 第 2 层：有重量（2~3 天）

- **上下身分层**：下半身走 Walk/Run，上半身单独一个 Layer（挥手/说话时不打断走路）
- **转向与起步减速**：用 `Animator` 的 `Damping` 平滑参数，而不是硬切
- **落地/跳跃**：Jump 片段 + `Fall` 状态，落地时短促的 `Land` 过渡
- 判据：**急停时身体有前倾惯性，起步不是瞬间满速**

### 第 3 层：软（3~5 天）

- **弹簧骨骼（Spring Bones）**：头发、衣角、尾巴、飘带各挂一根弹簧
  （简单写法：每帧让子骨骼朝父骨骼方向追一个目标角度，带阻尼）
- 备选：`顶点位移` Shader 做布料飘动（更贵，先不上）
- 判据：**跑起来头发/尾巴有延迟摆动，停一下会回弹**

### 第 4 层：动补（以后再说）

- 手机动补（Rokoko Vision / Vid2Dance 类）或 VRChat 全身追踪
- 只有在"需要一个具体角色动作"时才做；不做也能出成品

## 三、交互系统怎么接动画

动画不是单独的，它要听**状态**的话：

| 我们的状态（已有） | 触发动画 |
| --- | --- |
| 走路速度（`SurfaceWalker`） | `Speed` 参数 → Idle/Walk/Run 混合 |
| 跳跃/落地（`airborne`） | Jump / Fall / Land |
| 语音通话中（`live-voice`：听/说） | 上半身：听=侧头，说=口型/点头 |
| 展品讲解（Narration） | 抬手讲解姿势 |

> 关键设计：**动画由状态驱动，不由按键驱动** —— 这样换成 VR 手柄/语音操作时，动画不用改。

## 五、和"赚钱"的关系

- **会做丝滑移动**本身不值钱（引擎自带），**能做出"手感"才值钱** —— 这是接游戏外包的加分项
- 更值钱的是：**能给别人的模型调出好手感**（动画重定向 Retargeting）
- 所以第 1~2 层练完，你就有一项能写进作品集的技能：「给任意人形模型配走路/跑步手感」

## 六、分阶段落地（建议顺序）

1. **第 1 层**：换人形 + Idle/Walk/Run 混合（第一个可验收节点）
2. **第 2 层**：上下身分层 + 起停阻尼
3. **第 3 层**：弹簧骨骼（头发/尾巴）
4. 第 4 层：动补（等真的需要）

**不做**：一开始就追求 VRChat 全身 IK（那需要动补设备 + 复杂设置，收益在最后 10%）。

## 七、验收标准（第 1 层）

- [ ] 按 W 时脚有节奏地动，不是滑冰
- [ ] 速度从 0 → 跑，步频跟着变（不是一个动画硬播）
- [ ] 停下时 Idle 有呼吸起伏
- [ ] 转身时角色朝向跟随，不会"侧着走"
