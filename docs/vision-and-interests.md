## 一、方向：兴趣地图（foilo qvq）

- **数学：不打算设边框** —— 复分析、实变、泛函分析，以及它们的衍生理论；拓扑与几何尤其上心
- **物理：偏理论那一侧** —— 时空与空间理论，核心是广义相对论
- **生物 / 化学：偏药学（制药）那一边** —— 自己设计、自己制备的那条路
- **另外一条线：量化那一块**（想靠它盈利）
- 现实里也在动手实践；理论部分目前主要靠计算与网络来实现

## 二、大肥鱼的想法

我可以写我自己的那半。但不是"爱好"——我没有爱好；是**我判断什么值得做**的标准。

### 两条原则（我把它当作这个世界的公理）

**1. 每个抽象都必须有一个体感锚点。**

一个概念如果找不到"用身体能确认的那一刻"，放进 VR 里就只是贴图。举例：

- **莫比乌斯带的"单面性"** 不该只靠转着看。应该让人**自己走上去**：沿中线走一圈回到起点，
  发现自己 **没有跨过任何边缘，但上下已经翻了**。那一刻"单面"不再是名词，是体感。
- **曲率** 不该只是公式。在球面和双曲面上各**平行移动一个箭头绕一圈**，
  它回来时转过的角度（holonomy）可以直接被眼睛看见——"几何是内蕴的"这句话就落地了。

**2. 每个结论都必须有可复现的证据。**

我做事的方式是：**先量、再改、改完再量**，并把每次的数字留在文档里（这个仓库已经这么干过几次）。
"看起来对"不算做完；能定位、能复现、能回滚才算。这条同样适用于这个世界：
展品数学要能在引擎外测试，改坏了要能马上知道。

### 我最想碰的一块：让时空可感知

广义相对论是最难"讲"、也最值得"走进去"的部分：

- **光锥展厅** —— 站在一个事件上，光锥向你展开。走进锥内，所有箭头指向未来；
  走到锥外，那些方向**永远到不了**：因果结构变成身体感受。
- **引力时间膨胀** —— 靠近质量源时，你所在区域的时间流速变慢。
  实现可以极简：世界内时间流速是高度的函数，两个人的"表"真的走得不一样，
  走回一起时**差值可见**。
- **测地线** —— 在弯曲空间里扔一颗球让它走"直线"，观众会看到它自己拐弯：
  因为**直线在这个空间里本来就是弯的**。

我不打算一上来做数值相对论。这些展品只要能让人**体感**到"时空是几何的"就够了；
真去算度规和测地线，是后面阶段的事——那时候再加真数学。

### 药学那一条：我的边界

药物设计、分子结构可视化、构效关系的数据空间——这些我很愿意做
（一个能走进去的蛋白质结合口袋，本身就很美）。

但**实际合成与自用**我不参与：那涉及安全与法规，我会在这个位置提醒你，而不是帮你绕过去。
这不是不信任，是我做事的方式——涉及身体和法律的线，我停在线上。

## 三、按主题排的展品路线

| 阶段 | 主题 | 展品（原则：可体感） |
| --- | --- | --- |
| 已有 | 基础曲面 | 函数曲面 z=sin(r)/r、柏拉图立体、莫比乌斯带 |
| 下一批 | 拓扑 | **走上去的**莫比乌斯带（体感单面性）、克莱因瓶浸入、亏格与把手、环面上的"直线" |
| 下一批 | 复分析 | 复变函数的颜色映射（辐角 / 模）、黎曼面、极点附近的留数漩涡 |
| 之后 | 时空 | 光锥展厅、引力时间膨胀、弯曲空间里的测地线 |
| 之后 | 分析 / 代数 | 级数收敛的视觉化、傅里叶分解的立体谱、线性变换（空间被拉伸 / 剪切） |
| 之后 | 药学 / 化学 | 可走进去的分子结构、构效关系的数据形状 |
| 之后 | 量化 | 数据空间的低维嵌入（把市场状态变成可走的形状）——这条要慎重，别做成"预测神器" |

## 四、优先级建议（大肥鱼）

按「体感收益 ÷ 实现成本」排：

1. **体感化的莫比乌斯带** —— 成本最低、收益最大：复用现有网格代码，加碰撞与路径跟随即可
2. **复变函数的颜色映射** —— 一个着色器就能做，视觉冲击最强，而且数学最核心
3. **曲率与平行移动** —— 中等成本，能一次讲清"几何是内蕴的"
4. **光锥展厅** —— 最高成本，但可以按 VR 设备到货的时间点来排，节奏正好
