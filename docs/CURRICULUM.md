# 高中数学 → VR 课程地图（人教 A 版 2019 顺序）

> 目的：VR 世界的展品**按教材顺序排**，不让新手一进来就懵。
> 原则：**先集合 → 逻辑 → 不等式 → 函数 → …**，一个区一块板，走完等于过一遍必修。

## 〇、第 0 章：初高衔接（进入 VR 的第一站）

> 理由：高一上来就懵，八成不是"高中数学难"，而是**初中那套变形/解不等式的手感**没带过来。
> 所以 VR 入口顺序：**导览板 → 衔接区（第0章）→ 集合区（第1章）→ …**

| # | 衔接主题 | 一数对应 | 为什么必须有 |
| --- | --- | --- | --- |
| 0.1 | **等式变形**：因式分解、配方、分式、根式 | P2 初高衔接·等式变形方法回顾（34:42）<br/>BV1p14y1d7PV | 后面所有"化简"都靠它 |
| 0.2 | **不等式解法**：一元二次 / 分式 / 绝对值 / 高次 | P3 初高衔接·不等式解法梳理（29:13）<br/>BV1bc411c73k | 集合的区间表示、函数定义域都直接用 |
| 0.3 | **根的分布** | 衔接区·根的分布问题（24:08）<br/>BV1fX4y1L7ih | 高中不细讲、初中没学过，但二次函数题全在用它 |
| 0.4 | **二次函数三形态**（一般/顶点/交点） | 二次专题 P16–17 前置 | 判别式、最值、恒成立的共同底座 |
| 0.5 | **韦达定理与对称式** | 同上 | 根与系数关系，解析几何也用 |

### 第 0 章的 VR 三件套

1. **一图流**：`初高衔接·六个必备变形`（✅ 本次生成）
2. **可走展品**：「变形工作台」—— 三个可动手的台子（配方 / 十字相乘 / 二次不等式区间），站上去看指示
3. **笔记**：`My_Library/.../初高衔接-六个必备变形.md`

### 判断"要不要补衔接"的自测（三道就够）

- 能把 $x^2-5x+6$ 和 $2x^2+7x+3$ 都快速因式分解吗？
- 能解 $\dfrac{x-1}{x+2}\le 0$ 并写对区间吗？
- 能说出 $ax^2+bx+c>0$ 的解集和判别式 $\Delta$、开口方向的关系吗？

三条里有一条卡住 → 第 0 章必须走一遍，再进集合。

## 四、现有展品怎么归位

现在场里这些展品是**先做出来的数学美/直观**，不严格对教材章节：

| 现有展品 | 归到哪 |
| --- | --- |
| `Exhibit_Surface`（复变曲面） | 选修·复变/拓展区 |
| `Exhibit_Slopes`（一次函数斜坡） | 第 4 章前面的「函数直观」预热区 |
| `Exhibit_Fractions`（分数地砖） | 小学/初中衔接区 |
| `Exhibit_RiemannSqrt` | 拓展区 |
| `Exhibit_Mobius` / `WalkableMobius` | 拓展区（拓扑） |
| `Exhibit_BlackHole` | 拓展区（引力/趣味） |
| `Exhibit_ProjectMap` | 入口导览 |
| `Exhibit_MethodWall` | 入口方法墙（换元 + 双分类） |

> 结论：**入口保留「导览板 + 方法墙」两件**，往里走进**章节区**；
> 拓展展品集中在右侧/深处，不挡主线。
