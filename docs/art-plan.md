# 美术学习计划（foilo × 大肥鱼）

> 2026-10-17 立。原则：**每天 30~60 分钟，边学边往世界里放**——学的东西必须当天能用上。
> 从**道具**开始，不从角色开始。角色的三座大山（解剖 / 权重 / 布料）留到第 3 阶段。

## 一、三个阶段

| 阶段 | 时间 | 学什么 | 判据（能做出什么） |
| --- | --- | --- | --- |
| 1 · 基本功 | 2~4 周 | Blender 界面、盒子建模、挤出/倒角、UV 展开、导出 glb | 能做出台子/箱子/路灯/门框这类低多边形道具 |
| 2 · 造型语言 | 1~2 月 | 低多边形 + 硬边 + 发光描边的风格、材质与打光 | 能按风格做出 3 个场景道具并替换占位方块 |
| 3 · 角色 | 3 月以后 | 鱼这类"没有手指/没有布料"的角色、绑定与权重 | 能替换程序化的吉祥物鱼 |

## 二、20 个小练习（每个都对应世界里的一个坑位）

**阶段 1：道具**

1. 立方体 → 一个**展位台子**（替换 `Slot_1..4` 的圆柱）
2. 台子加**边缘倒角**，看同一模型在"有没有倒角"下的高光差别
3. 一根**路灯**（简单柱 + 发光球）
4. 数学区**入口框**：两根立柱 + 横梁（替换 `MakeBar` 的方块）
5. 一个**指示牌**（1/2、1/3、1/4 那三块小牌子就能用它）
6. 一个**长椅**（走累了能坐？先只做外观）
7. 一个**台阶**：3 级，用来连接不同高度的台子
8. 一个**低矮围墙**（数学区边界感）
9. 一根**旗杆 + 布片**（学一点点形状动画）
10. 把上面 4 件放进场景，统一材质与颜色

**阶段 2：风格与场景**

11. 画 3 张概念图（数学区 / 出生点 / 黑洞），定色板
12. 做一套**材质球**（哑光 / 金属 / 自发光 / 半透明）并给道具换上
13. 做一个**地面砖**带网格与磨损感（替换程序化网格贴图）
14. 做**入口处的一棵树或一株植物**（低多边形 + 硬边）
15. 做**路灯的灯柱细节**（螺丝、接缝），体会"细节密度"
16. 用 Poly Haven 的 HDRI 试环境光，和自己打光对比
17. 做**数学区的招牌**（文字 + 发光边框）
18. 做**分数地砖的实体版**（三行不同份数的贴片模型）

**阶段 3：角色**

19. 用低多边形做**一条鱼**（参考现在的程序化大鱼），先不绑定
20. 给鱼做**骨架 + 权重**，替换 `MascotBody` 的程序化版本（先只替换大鱼）

**不能直接拿**：

- **游戏/影视里扒出来的模型**（"某某游戏提取"）—— 侵权，别碰。
- **CC-BY-NC（非商用）** 的模型：我们仓库是公开的、项目未来可能商业化，**不要用**。
- 来源不明的"免费模型包"：没有许可证就等于没有授权。

**规矩（从现在开始执行）**：

1. 每引入一个第三方素材，就往 `unity/Assets/Art/CREDITS.md` 里加一行：
   `文件名 | 来源链接 | 作者 | 许可证`。
2. 自己做的资产不用记（我们自己的版权）。
3. **不把别人的模型塞进提交历史里再删**——git 里删不干净；先看清许可证再放进来。

## 四、交付约定

- 模型放 `unity/Assets/Art/`（`.blend` 源文件**只放本地**，仓库收导出文件）。
- **导出格式用 FBX，不是 glb**（2026-10-17 实测踩坑）：
  Unity **原生不导入 glTF/glb** —— 会被当成普通文件（`DefaultImporter`），
  `Resources.Load` 拿不到、模型根本不会出现在场景里。**FBX** 是 Unity 原生支持的格式。
  Blender 里：`文件 → 导出 → FBX (.fbx)`，勾「应用修改器」，缩放用 `FBX_SCALE_ALL`（尺寸直接是米）。
  （要真用 glb，得额外装 `glTFast` 之类的包 —— 现在不装。）
- 运行时加载：放在 `unity/Assets/Resources/Art/` 下，代码里
  `Resources.Load<GameObject>("Art/名字")`；缺了会自动退回程序化占位（不会崩）。
- 每个模型旁边的 `.meta` 必须进库（缺了 GUID 会重排，场景引用会连错）。

## 五、参考实现（大肥鱼先跑通的那条流水线）

`tools/blender_scripts/make_pedestal.py` —— 无界面生成「展位台子」，foilo 可以拿它对照：

```powershell
& "C:\Program Files\Blender Foundation\Blender 5.2\blender.exe" -b `
  -P tools\blender_scripts\make_pedestal.py -- `
  unity\Assets\Resources\Art\SlotPedestal.fbx
```

产物：384 顶点 / 338 面 / 25 KB FBX，直径 3.6 m、高 0.5 m、一圈倒角。
Unity 侧已接好：`Resources/Art/SlotPedestal` 存在就用它当台子外观，
否则退回程序化圆柱；`Verify` 会硬检查「有资产却没用上」= FAILED。

**你手做的第一遍建议照这个顺序**（10 分钟）：
加圆柱 → `S` 缩到 半径 1.8 → 顶面收边 0.92 → `Ctrl+B` 倒角 0.03/3 段 →
导出 FBX 覆盖这个文件 → 在 Unity 里按 Play，台子就变成你的了。
